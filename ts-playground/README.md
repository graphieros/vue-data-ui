# ts-playground

Scaffolds for all components with `script setup lang="ts"`

Use Node.js 24 and pnpm 12.15.0. Build the library at the repository root first, then
run `pnpm install --frozen-lockfile` here. Use `pnpm run dev` for development and
`pnpm run build` for type checking and a production build. After rebuilding the
library, run `pnpm install` here to refresh the local `file:` dependency snapshot.
